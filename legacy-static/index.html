About Me

모델 구현에서 배포와 운영까지, 서비스 관점으로 AI를 다룹니다.

중학교 AI 동아리 부장을 맡으며 인공지능에 관심을 갖기 시작했고, 고등학교 입학 후 LLM과 비전 기술을 활용한 프로젝트를 이어왔습니다. 모델 성능뿐 아니라 제한된 자원, 추론 속도, 메모리 사용량, API 연동까지 함께 고려하는 개발을 지향합니다.

협업에서는 API 형식과 데이터 구조처럼 공통 기준을 먼저 정리해 역할을 분리하고, 병렬적으로 개발할 수 있는 환경을 만드는 데 강점이 있습니다.
